Visão Geral

Sistema de formulário de OS com envio por email

Aplicação web single-page para técnicos de campo registrarem ordens de serviço, anexarem fotos/equipamentos e enviarem relatórios por email. Funciona offline-first com persistência local.

Regras de Negócio

Principais regras do sistema

  • UC deve conter apenas dígitos numéricos
  • Data do serviço não pode ser futura
  • Hora fim deve ser diferente da hora início
  • Máximo de 12 anexos por formulário
  • Cada anexo limitado a 8 MB
  • Compressão progressiva de imagens até 650KB
  • Auto-save debounced a cada 1 segundo
  • Campos condicionais ocultos são excluídos do email
  • Validação pula campos hidden (display:none)
  • saveState só ativa com UC+OS preenchidos
  • Nomes de tipo-ordem devem casar exatamente com chaves de retorno
  • Destinatários exclusivamente de SMTP_TO (não do formulário)
  • Datas invertidas no email: YYYY-MM-DD → DD-MM-YYYY
  • Verificação de duplicidade antes de reenvio
