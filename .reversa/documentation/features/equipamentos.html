Equipamentos

equipment.js

Requisitos

Visão Geral

Gerencia a adição, remoção e coleta de equipamentos instalados ou retirados durante a ordem de serviço. Cada equipamento possui tipo (Instalado/Retirado), categoria e número de série.

Regras de Negócio

IDRegraConfiança
RN01Cada equipamento tem 3 campos: status (Instalado/Retirado), categoria (Medidor/Display/Conjunto/TC/TP) e número🟢 CONFIRMADO
RN02Número de equipamento não pode ser duplicado (validado externamente em validation.js)🟢 CONFIRMADO
RN03Seção de equipamentos é opcional — formulário pode ser enviado sem equipamentos🟢 CONFIRMADO
RN04Ao restaurar um registro, equipamentos são re-renderizados no DOM🟢 CONFIRMADO

Estrutura de Dados

// Cada equipamento no array state.equipamentos[] { tipo: "Instalado" | "Retirado", categoria: "Medidor" | "Display" | "Conjunto" | "TC" | "TP", numero: string // número de série, unique no array }

Layout da Linha

Ciclo de Vida

init → DOM ready │ ├─[click "+Equipamento"] → addEquip() │ ├─ create row HTML │ ├─ append to #equip-list │ └─ hideEmptyEquip() │ ├─[click ✕ na row] → remove row + showEmptyEquip() se vazio │ ├─ collectEquipamentos() → percorre rows, monta array │ └─ renderEquipamentos() → limpa lista, recria rows do state └─ showEmptyEquip() se state.equipamentos estiver vazio
