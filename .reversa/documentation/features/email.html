Email

email.js send.js (Netlify Function) contracts/

Requisitos

Visão Geral

Sistema de composição e envio de email com SMTP. Opera em duas camadas: frontend compõe o corpo textual a partir dos dados do formulário, backend (Netlify Function) recebe e despacha via nodemailer.

Regras de Negócio

IDRegraConfiança
RN01Data é invertida de YYYY-MM-DD para DD-MM-YYYY no corpo do email🟢 CONFIRMADO
RN02Apenas campos de retorno preenchidos (existentes em data.retorno) são incluídos no email🟢 CONFIRMADO
RN03Hidden fields (display:none) são filtrados por getRetornoData() e não aparecem no email🟢 CONFIRMADO
RN04composeEmail() duplamente protege — verifica field.nome in data.retorno antes de incluir🟢 CONFIRMADO
RN05Equipamentos são incluídos se data.equipamentos.length > 0; se vazio, seção omitida🟢 CONFIRMADO
RN06Destinatários vêm exclusivamente de SMTP_TO (env var), não do formulário🟢 CONFIRMADO
RN07Anexos são validados no backend (máx 12, máx 8MB cada)🟢 CONFIRMADO
RN08Backend rejeita se SMTP_FROM está ausente ou em formato inválido🟢 CONFIRMADO
RN09Backend rejeita se SMTP_TO não está configurado ou contém emails inválidos🟢 CONFIRMADO
RN10TLS rejectUnauthorized: false é intencional para certs auto-assinados em produção🟢 CONFIRMADO
RN11Campos vazios são substituídos por "—" (em dash) no email; campos de retorno vazios mostram "(nao preenchido)"🟢 CONFIRMADO

Design Técnico

Arquitetura

┌──────────────────────┐ POST /api/send ┌─────────────────────────┐ │ Frontend (SPA) │ ──────────────────────> │ Netlify Function │ │ │ { subject, text, │ (netlify/functions/ │ │ composeEmail(data) │ attachments } │ send.js) │ │ updateLivePreview() │ │ │ │ │ <───────────────────── │ nodemailer → SMTP │ │ DOM.previewCorpo │ { success, to } │ │ └──────────────────────┘ └─────────────────────────┘

Fluxo de Composição (composeEmail)

composeEmail(data) │ ├─ iniciaisFields.forEach(field) │ ├─ raw = data.iniciais[field.nome] || "" │ ├─ if date → reverse ("2026-06-15" → "15-06-2026") │ └─ normalizeText(label) + ": " + normalizeText(val) + "\n" │ ├─ if data.equipamentos.length > 0 │ ├─ "\n\nEQUIPAMENTOS:" │ └─ forEach eq → "CATEGORIA STATUS Nº NUMERO\n" │ └─ retornoFields.forEach(field) ├─ if !(field.nome in data.retorno) → skip └─ normalizeText(label) + ": " + normalizeText(val || "(nao preenchido)") + "\n"

Exemplo de Saída

ORDEM DE SERVICO: 2026-06-001 TIPO DE ORDEM: LIGACAO NOVA DATA: 15-06-2026 TECNICO: JOAO SILVA MUNICIPIO: SOBRAL [...] EQUIPAMENTOS: MEDIDOR INSTALADO Nº 123456 DISPLAY INSTALADO Nº 789012 RETORNO: SITUACAO DO SERVICO: LIGADO LEITURA: 04521 MEDIDOR INSTALADO: SIM

Normalização de Texto

normalizeText(str) → str .normalize("NFD") .replace(/[\u0300-\u036f]/g, "") .replace(/ç/g, "c") .replace(/Ç/g, "C") .toUpperCase()
