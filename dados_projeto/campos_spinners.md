## Observações sobre Valores

- **Asterisco (*)**: presente nos valores de `ElementsFromString` para itens obrigatórios
  - Ex: `"LIGAÇÃO EXECUTADA? *,SIM,NÃO"` → "LIGAÇÃO EXECUTADA? *" é exibido como primeiro item
- **Acentos**: preservar acentos como aparecem no código fonte:
  - "MEDIÇÃO AVARIADA?" (com acento em O)
  - "MEDIDOR BT RETIRADO/CORTADO" (sem acento em RETIRADO)
  - "LIGAÇÃO EXECUTADA?" (com acento em A)
  - "NECESSÁRIO LINHA VIVA?" (com acento em A)
  - "NÃO" (com acento, codificado como \u00C3O no YAIL mas exibido como NÃO)
  - "NÃO" vs "NAO" — o código usa consistentes comparações com "NÃO" acentuado
- **Duplicatas**: "LIGAÇÃO NOVA SIMULTÂNEA" e "LIGAÇÃO NOVA ISOLADA" também aparecem como entradas independentes além do combo "LIGAÇÃO NOVA (SIMULTÂNEA/ISOLADA/MT)"
